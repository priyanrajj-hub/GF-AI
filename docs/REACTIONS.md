# Ada Wong AI: Reaction Engine & Backchanneling

Ada's reaction modeling system delivers real-time emotional and physical responses rather than static tags.

## ⚡ Multi-Tier Pipeline

1. **Fast Local Rule Classifier (<50ms)**:
   - Detects user intent (compliment, praise, teasing, stress, sadness, achievement, pokes) locally in browser.
   - Triggers instantaneous micro-reactions (head tilt, blush, gasp, lean) before LLM response generation begins.
2. **Backchanneling Loop (3-6s interval)**:
   - Delivers subtle listening cues (small nods, thoughtful head tilt, eye tracking) while the user speaks or types.
3. **LLM Structured Reaction Reconciliation**:
   - Reconciles the high-level LLM reply with physical gestures, facial blendshapes, voice modulation, and particle FX.
4. **Anti-Repetition & Familiarity Tracking**:
   - Ensures no reaction repeats twice consecutively.
   - Tracks streaks, jokes, and preferences without emotional guilt or clinginess.

## 🛑 Crisis Protocol Priority Override
In accordance with ethical AI guidelines:
- If user distress or self-harm is detected, the crisis protocol overrides all playful reactions, jokes, memes, and teasing immediately.
- Ada enters a gentle, supportive, calm posture and provides national and international crisis helpline resources.
